# AutoTabber

AutoTabber organizes browser tabs into groups based on user-defined URL rules.

## Language

**Saved tab-group rule**:
A saved AutoTabber configuration that associates a name, color, and URL patterns with tabs to organize.
_Avoid_: Group (ambiguous)

**Chrome tab group**:
A browser-created collection of tabs in one window with a title and color.
_Avoid_: Tab-group rule, group (ambiguous)

**Tab grouping opt-out**:
A per-tab preference that prevents AutoTabber from automatically placing that tab into a group.
_Avoid_: URL exclusion, manual override
